[입력 구조]
필수 열: id, final_score, captured_at, tags.
추가 열이 있을 수 있으며 인덱스는 연속 정수가 아닐 수도 있고 중복될 수도 있습니다.
가상 입력 예시:
pd.DataFrame({
    "id": [1, 2, 3, 4],
    "final_score": ["8.5", None, 12, -2],
    "captured_at": ["2026-10-01", "2026-10-02", "bad-date", "2026-10-03"],
    "tags": [["대칭"], ["야경"], [], None]
})

[출력 구조와 원본 보존]
- 새로운 DataFrame을 반환하고 원본을 직접 변경하지 마세요.
- 남은 행의 인덱스·순서·열 순서를 유지하세요. 인덱스를 재설정하지 마세요.
- 추가 열과 tags 값은 그대로 보존하세요. 태그 목록을 수정하거나 문자열을
  JSON으로 파싱하거나 결측 태그를 대체하지 마세요.
- 중첩된 태그 객체까지 독립적으로 복제할 필요는 없지만, 함수 안에서 수정하면 안 됩니다.
- year_month 같은 새 열을 추가하거나 그룹 집계, 3개월 필터, 중복 행 제거를 하지 마세요.
- final_score는 float64, captured_at은 시간대 없는 datetime64[ns]로 반환하세요.

[점수 정제]
1. "8.5", " 7 " 같은 유효한 숫자 문자열은 숫자로 바꾸세요.
2. None, pd.NA, NaN, 빈 문자열, 비수치 문자열은 점수 결측으로 보고 행을 제거하세요.
3. True/False 같은 불리언, 복소수, 양·음의 무한대도 유효 점수가 아니므로 행을 제거하세요.
4. 나머지 유한 점수는 0.0~10.0 사이로 클리핑하세요. -2는 0.0, 12는 10.0입니다.
5. 원래 0점과 10점인 행은 유지하세요. 결측 점수를 0점이나 평균으로 채우지 마세요.

[날짜 정제]
1. YYYY-MM-DD 또는 YYYY-MM-DD로 시작하는 ISO 형태 날짜·시각 문자열과
   Python date/datetime, pandas Timestamp를 지원하세요. 앞뒤 공백은 제거해도 됩니다.
2. 누락·잘못된 날짜·존재하지 않는 날짜·datetime64[ns] 범위 밖 날짜는 NaT로 두세요.
   날짜가 잘못되어도 점수가 유효한 행은 삭제하지 마세요.
3. 숫자를 Unix timestamp나 나노초 시각으로 해석하지 마세요.
   0, 20261001, True 같은 날짜 입력은 NaT입니다.
4. now, today 같은 상대 날짜와 01/02/2026 같은 모호한 날짜 문자열은 NaT입니다.
   같은 입력의 결과가 실행 날짜나 환경에 따라 달라지면 안 됩니다.
5. 시간대가 있는 날짜는 현지 촬영 시각을 유지하고 시간대만 제거하세요.
   예: 2026-10-01T00:30:00+09:00 -> 2026-10-01 00:30:00.
   UTC로 변환하여 촬영 월이 바뀌지 않도록 하세요.

[빈 입력과 예외]
- DataFrame이 아닌 입력(None, list, dict, str, int 등): TypeError.
  오류 메시지에 "DataFrame"을 포함하세요.
- 중복된 열 이름: ValueError. 메시지에 "중복"을 포함하세요.
- 필수 열 누락: ValueError. 메시지에 "필수 열 누락"과 빠진 열 이름을 포함하세요.
- 단, 행과 열이 모두 없는 pd.DataFrame()은 예외 없이
  id, final_score, captured_at, tags 순서의 표준 열을 가진 빈 결과로 반환하세요.
- 열은 있는데 필수 열이 일부 빠진 빈 DataFrame은 ValueError입니다.
- 표준 열이 있는 빈 입력 또는 정제 후 모든 행이 제거된 경우에도
  final_score=float64, captured_at=datetime64[ns]를 유지하세요.
- 동일 데이터를 두 번 정제해도 결과가 같아야 합니다.
