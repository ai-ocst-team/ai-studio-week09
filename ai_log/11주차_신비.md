```text
각 시나리오마다 [사전 조건 / 수행 절차 / 기대 결과 / 실제 관찰 기록(체크리스트 포함) / 첨부 스크린샷 링크] 표가 들어가고, 하단에 pytest 실행 요약 섹션이 들어가도록 깔끔하게 작성해줘.

```

### 2. AI 생성 내용 (핵심 부분 발췌)

AI는 `docs/week11_verification.md`의 검증 구조를 작성하였다. 초기 화면 및 UTF-8 정상 CSV, CP949 정상 CSV, 필수 컬럼 누락 CSV의 사전 조건·절차·기대 결과·관찰 기록·스크린샷 경로·pytest 요약을 표로 분리하였다.

```markdown
| 구분 | 내용 |
|---|---|
| 사전 조건 | `sample_data/sample_photos_broken.csv` (`final_score` 누락) |
| 수행 절차 | 잘못된 CSV 업로드 후 오류 안내 확인 |
| 기대 결과 | 필수 컬럼 누락을 `st.error`로 안내하고 분석 출력 중단 |
| 실제 관찰 | `[확인 후 기입]` |
| 판정 | ☐ 통과 ☐ 실패 ☐ 미실행 |
```

### 3. AI 생성 결과 검토 및 보완 필요 사항

AI가 생성한 수동 검증 보고서는 각 시나리오의 수행 절차와 기대 결과를 정리한 양식으로, 실제 실행 결과는 포함되지 않았다. 따라서 테스트 수행 후 관찰 내용을 직접 기록하고, 미실행 상태로 표시된 항목을 수정할 필요가 있었다.

### 4. 수정·보완 내역

Streamlit 대시보드를 직접 실행하여 초기 화면과 CSV 3종의 동작을 확인하였다. 실행 결과를 바탕으로 KPI 수치, 필터 적용 결과, 오류 메시지를 보고서에 작성하고 실제 스크린샷을 첨부하였다. 또한 pytest 실행 결과를 반영하여 검증 보고서를 보완하였다.
