## [2026-11-23] `st.sidebar.pills` 선택 해제(`None`) 및 A/B컷 기준 역전(`a <= b`) 방어 검증 (담당: 하정윤)
- **대상 모듈**: `app.py` / **관련 커밋**: `ed548ee`
- **품질 관점**: [방어적 UX · 백엔드 계약 준수]
- **초기 프롬프트 (요지)**:  
  "사이드바 태그 선택은 드롭다운 화살표 문제를 없애기 위해 `st.sidebar.pills`로 전환하고, 사용자가 A컷·B컷 기준 점수를 직접 조절할 수 있게 구성하라."
- **발견한 문제 및 사전 통제 (계약 대조)**:  
  1. **[위젯 반환값 `None` 가능성]**: `st.sidebar.pills(..., selection_mode="single")`는 사용자가 이미 선택된 알약 버튼을 한 번 더 누르면 선택이 해제되어 `None`을 반환하므로, 그대로 `filter_analyses(..., selected_tag=picked_tag)`에 넘기면 `"전체"`로 처리되지 않고 타입/필터 오동작 우려가 있음.
  2. **[백엔드 예외 전파 위험]**: `backend.assign_cut_grades`는 `a_cutoff <= b_cutoff` 입력 시 `ValueError`를 발생시키도록 구현되어 있어, UI 슬라이더를 반대로 움직이는 순간 앱이 Traceback으로 멈출 수 있음.
- **수정 및 방어 내역 (`app.py` 사이드바 입력부)**:  
  1. `selected_tag = picked_tag or ALL_TAGS`로 `None` 반환 시 `"전체"`로 즉시 폴백하고, 파일 간 태그 목록이 바뀔 때도 안전하게 초기화.
  2. `if raw_a_cutoff <= raw_b_cutoff:` 선행 검사를 두어 `st.sidebar.warning`으로 원인·기준을 안내하고 기본값(`8.0 / 6.0`)을 안전 적용하도록 방어.
- **검증**:  
  - 로컬 서버(`http://localhost:8512`) 실브라우저 동작 및 `AppTest` 9개 시나리오(업로드 전 중단, 정상 UTF-8, `A<=B` 경고 폴백, `pills` 선택·`None` 해제, 챗봇 응답·초기화, `cp949` 경고, 비정상 점수 행 제외 경고, 컬럼 누락 에러, 0바이트 빈 파일 에러) 전원 `PASS`, `Streamlit deprecation warnings: 0` 확인.
  - `python -m pytest -q`: `206 passed` 확인.
- **판단 메모**:  
  백엔드가 `ValueError`로 잘못된 도메인 계약을 엄격히 막아 두었더라도, 웹 UI 계층에서는 이를 그대로 크래시시키지 않고 사전 조건 검사와 `st.warning` 안내로 흡수해야 방어적 UX 원칙(실패 시 다음 행동 안내 및 앱 지속 동작)을 지킬 수 있음을 확인함.
