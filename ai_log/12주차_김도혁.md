후속 요청에서 사용자는 네 파일의 업데이트 초안을 요청하면서 보안 명령 실행 결과를 `[실행 결과 붙여넣기]`로 비워 두도록 했다.

### AI 초기 제안·코드

AI는 전용 worktree의 `.gitignore`에 Secrets 파일 제외 규칙을 추가하고, `requirements.txt`에서 Streamlit 최소 버전을 올렸다. README 최상단에 공식 URL을 추가하고 보안 체크리스트에 점검 기록을 작성했다. 이후 12주차 README 섹션과 체크리스트 초안을 대화에서 별도로 제시했다.

### 발견한 문제·판단

- `.gitignore`는 이미 추적 중인 파일을 Git 이력에서 제거하지 않는다. AI는 파일 제외 확인과 이력 확인을 별도 점검으로 다뤘다.
- `git log`의 파일명 패턴 검색은 다른 이름의 파일이나 코드 내용에 포함된 비밀값을 찾지 못한다. 로컬에 없는 참조도 검색하지 않는다.
- 사용자가 나중에 요청한 README·체크리스트 초안 전체는 기존 파일에 적용되지 않았다. 기존 체크리스트에는 이전에 실행한 명령의 결과가 기록되어 있으므로, 초안의 결과 자리표시자와 구분해야 한다.

### 수정·채택

AI는 소유 파일 네 개를 수정했다. 앱·백엔드·피드백 로그는 직접 수정하지 않았다. 별도 브랜치에서 최신 `main`을 fast-forward로 반영했을 때 `app.py`는 원격 변경에 따라 갱신됐다. README·체크리스트의 후속 초안은 대화에서 제시했으며 전체 적용 또는 사용자 검토 완료로 기록하지 않는다.

### 검증·Git 이력

- `.streamlit/secrets.toml`, `secrets.toml` 제외 규칙은 `git check-ignore`로 확인했다.
- `git log --all --full-history -- '**.env*' '**secrets.toml*'`는 당시 로컬 참조 기준 출력이 없었다. 기준 `main`은 `d3860a6`이다.
- `git diff --check`를 통과했다. 이후 최신 `main`의 `b9da6d9`를 작업 브랜치에 반영했다.
- 변경사항은 미커밋 상태다. 테스트 실행이나 사용자의 코드 리뷰 완료는 확인하지 않았다.

## 2. Streamlit Cloud Secrets와 배포 상태 확인

### 프롬프트

실제 사용자 후속 요청의 해당 부분. 더미 값은 생략했다.

> 기존 배포 앱(https://photo-grader.streamlit.app/) 재배포 및 Secrets 설정:  
> share.streamlit.io 앱 설정의 Secrets 메뉴에 13주차 대비 더미 값 등록 테스트(코드·Git에는 절대 커밋 금지).  
> Task 1·2 머지 후 https://photo-grader.streamlit.app/ 자동 재배포 로그 확인 및 README.md 최상단에 공식 URL 기재.

### AI 초기 제안·코드

AI는 기존 Secrets를 보존하면서 더미 값만 추가하고 관리 로그와 공개 앱을 확인하기로 했다. GitHub에서 Task 1 백엔드 PR #20과 Task 2 UI PR #21의 `main` 병합을 확인하고, Streamlit 팀 작업공간에서 공식 앱 관리 화면을 열었다.

### 발견한 문제·판단

Secrets 편집기의 저장 단계에서 자동 승인 검토가 기존 설정이 덮어써질 위험을 이유로 동작을 거부했다. 편집기의 예시 표시가 기존 저장값인지 확정하지 않은 상태였으므로 AI는 저장을 중단했다. AI는 실제 비밀값을 대화나 저장소에 기록하지 않고 사용자가 기존 설정을 직접 확인하도록 안내했다.

### 수정·채택

사용자는 Secrets 설정을 직접 저장했다고 보고했다. 이어 앱이 정상 작동하고 Mock 함수도 정상 출력됐다고 직접 보고했다. AI는 저장 후 재접속을 시도했으나 브라우저 도구 오류로 독립적으로 재확인하지 못했다.

### 검증·Git 이력

- AI가 공개 앱에서 A/B컷 대시보드와 AI Culling Q&A 탭을 확인했다.
- 관리 패널에 `ai-ocst-team/ai-studio-week09/main/app.py`가 표시됐다. 2026-11-24 UTC 로그에서 의존성 처리 완료와 Uvicorn 서버 시작을 확인했고, 설치된 Streamlit은 1.67.0이었다.
- 확인한 로그만으로 배포의 정확한 커밋 SHA나 해당 머지가 자동 재배포를 시작했는지는 확정하지 않았다. 저장 후 정상 동작과 Mock 출력은 사용자 보고를 근거로 한다.
- 공식 URL을 추가한 README는 아직 커밋·푸시 전이다. 실제 키와 더미 설정은 이 기록에 포함하지 않았다.
