## 2. AI 생성 결과

`backend.py`에 태그 설명 사전과 정제 제외 행 수, 컷 등급 부여, 등급별 집계, Mock 답변 함수를 추가했다. 컷 분류의 핵심은 아래 순서다.

```python
graded.loc[scores >= b_cutoff, "cut_grade"] = "B컷"
graded.loc[scores >= a_cutoff, "cut_grade"] = "A컷"
```

모든 행을 보류로 시작하고 B컷 기준을 적용한 뒤 A컷 기준을 적용한다. Mock은 질문과 제공된 집계 정보를 사용하며 13주차에도 함수 호출 형식을 유지한다.

## 3. 검토 내역

Codex는 단순 건수 집계에서는 해당 등급이 없는 경우 키가 빠질 수 있고, Mock 응답에서 참·거짓으로 수치를 확인하면 실제 0건이 누락될 수 있다는 점을 점검했다. 사용자는 코드를 직접 확인한 뒤 문제가 없다고 알렸다.

## 4. 수정 및 보완

등급 집계는 빈 결과에도 A컷·B컷·보류 키를 각각 0으로 반환하도록 했다. Mock은 통계 키의 존재를 확인해 A컷·B컷이 0건이어도 표시한다. 점수 기준의 허용 범위와 순서를 확인하고, 6.0과 8.0이 각 등급에 포함되는지와 원본 DataFrame이 유지되는지 테스트에 담았다. 기존 백엔드 함수는 변경하지 않았다.
