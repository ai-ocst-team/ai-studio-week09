# 보안 체크리스트 — 5주차 S1~S10

| 번호 | 강의 점검 항목 | 상태 / 필요한 증빙 |
|---|---|---|
| S1 | 실존 인물 PII 없이 더미 데이터 사용 | 테스트는 가상 데이터. 제출자명과 Git author는 과제 귀속용. 생성 후 전 파일·증빙 확인 필요 |
| S2 | 외부 AI에 기밀·타인 코드·PII 미입력 | 실제 Copilot 전송 내용 본인 확인 필요. 기존 검증 코드는 팀 공유 사용 범위 확인 |
| S3 | 외부 자료 출처·라이선스 확인, 비식별 | 팀 코드 출처는 report.md 참고 절에 기록. 팀 내 재사용 권한 확인 필요 |
| S4 | API 키·비밀번호 하드코딩 없음 | 골격은 키 없음. 생성 후 코드와 증빙 다시 확인 |
| S5 | .env 제외 및 git ls-files 미추적 | 개인 .gitignore 준비. 실제 제출 저장소에서 확인 필요 |
| S6 | 전체 커밋 이력의 키 노출 없음 | 미확인. 개인 폴더만으로 팀 전체 이력 통과 판정하지 않음 |
| S7 | 로그·스크린샷·출력에 비밀 없음 | 실제 생성·검증 증빙 확인 필요 |
| S8 | 프롬프트·채택·수정 기록 첨부 | 준비 양식 있음. 실제 Copilot 기록 및 해시 미확보 |
| S9 | LLM 입력·출력 검증 | 명세와 사전 테스트 준비. 구현 후 통과 증빙 필요 |
| S10 | 시스템 프롬프트에 비밀 없음 | 실제 런타임 프롬프트를 본인이 점검할 것 |

팀 전체 이력·전원 교차 확인은 별도 미완료. 체크한 날짜·확인자·근거를 실행 후 기록한다.
