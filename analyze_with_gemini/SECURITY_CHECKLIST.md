# 보안 체크리스트 — 5주차 S1~S10

팀명: 아트서강 · 담당자: 김도혁 · 대상 함수: analyze_with_gemini. 작성자가 기재한 확인 결과를 정리했다. 사용자 확인과 도구가 직접 검사한 범위를 구분한다.

| 번호 | 강의 점검 항목 | 상태 / 필요한 증빙 |
|---|---|---|
| S1 | 실존 인물 PII 없이 더미 데이터 사용 | 통과, 테스트는 가상 데이터 활용|
| S2 | 외부 AI에 기밀·타인 코드·PII 미입력 | 통과 |
| S3 | 외부 자료 출처·라이선스 확인, 비식별 | 통과 |
| S4 | API 키·비밀번호 하드코딩 없음 | 통과 |
| S5 | .env 제외 및 git ls-files 미추적 | 팀 공용 .gitignore에 .env·.venv/·__pycache__/ 포함. 현재 로컬 추적 목록에서 해당 파일 미발견. 작성자도 확인 완료로 기재 |
| S6 | 전체 커밋 이력의 키 노출 없음 | 확인 |
| S7 | 로그·스크린샷·출력에 비밀 없음 | 확인 완료 |
| S8 | 프롬프트·채택·수정 기록 첨부 | 원본 커밋·Codex 검토·수정·실제 pytest 결과 기록. Copilot 전송 전문 대조 및 수정 커밋 확인 완료(작성자 확인). 정확한 수정 해시는 이 로컬 사본에서 미확인|
| S9 | LLM 입력·출력 검증 | 입력·응답 검증 구현 확인. 개인 43개 및 전체 98개 테스트 통과. 실제 모델 안전성 검증은 아님 |
| S10 | 시스템 프롬프트에 비밀 없음 | 통과|

팀 전원 보안 교차 확인은 사용자가 완료했다고 확인했다. 본 문서의 통과 표시는 작성자 확인에 근거하며, 보조 도구가 팀 전체 이력을 새로 감사한 결과를 의미하지 않는다.
